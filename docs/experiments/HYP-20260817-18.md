# HYP-20260817-18: Wan2.2 native video VAE with DINOv3-only drift

## Hypothesis

The framewise Wan VAE does not provide enough benefit to justify departing from
the pretrained model's native representation. Joint video encoding should keep
the DiT input aligned with Wan2.2 pretraining, while a DINOv3-only drifting loss
avoids supervising the temporally compressed Wan latent space directly.

## Fixed inputs

- Model: `Wan-AI/Wan2.2-TI2V-5B-Diffusers`
- Dataset: Demo5 clean 10k
- Manifest: `/mnt/dataset/demo5_dataset/manifests/demo5_clean_10k_f49_seed10.csv`
- RGB frames: zero-based indices 30/31/32/33/34 at 640x384
- Candidates: 64
- DINOv3: `dinov3_vitb16`, LVD-1689M, blocks 2/5/8
- DINOv3 weights: `/mnt/home/renqian/imgGen/runtime/MODEL/dinov3/model.safetensors`
- Learning rate: `1e-7`, warmup 200

## Treatment

- Wan VAE: native joint video encode/decode (`framewise_vae=False`)
- DiT latent shape: `[48, 2, 24, 40]`
- DINOv3 drift weight: 1.0
- Wan local latent drift weight: 0.0
- Trajectory latent drift weight: 0.0
- Static negative weight: 1.0; each predicted RGB frame uses the preceding real
  frame in DINOv3 space
- DINOv3 supervision: the four decoded future RGB frames; the condition frame
  is excluded
- Formal steps: 10,001

## Status

Implementation and distributed smoke validation complete.

## Validation

- Infra profile: `aliyun-47-116-39-128-1017`
- Seven-GPU FSDP, 64 candidates, `MAX_ITER=2`, one optimizer step
- Input confirmed as `[48, 2, 24, 40]`; DINOv3 decoded supervision remained
  four future RGB frames
- Total/DINOv3 loss: 10.0097
- Block losses: 9.9635 / 10.5816 / 9.4839 for blocks 2/5/8
- Peak allocated memory: 36.31 GB/GPU
- Forward/backward/optimizer time: 10.95 / 19.67 / 0.80 seconds
- Test result: 10 passed

Compared with the preceding framewise-VAE, latent-plus-DINO smoke, peak memory
fell from 65.73 to 36.31 GB/GPU and backward time fell from 29.89 to 19.67
seconds. This is the combined effect of native temporal compression and removing
the latent drift field; the smoke does not isolate their individual effects.
