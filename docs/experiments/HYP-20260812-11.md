# HYP-20260812-11: Increasing TFD class-conditional sample count

## Hypothesis

Increasing the number of generated, positive, and anchor samples per ImageNet class condition from `4/4/4` to `8/8/8` reduces the variance of the mini-batch feature-distribution estimate and can improve one-step generation quality.

## Controlled recipe

- Dataset: official TFD/DMD2 ImageNet-64 LMDB, 1,281,167 images and 1,000 classes.
- Teacher, feature layers, drift radii, feature-noise distribution, optimizer, learning rate, warmup, precision, and seed remain the paper-aligned recipe recorded in HYP-20260810-09.
- Changed class-conditional counts: 8 generated, 8 positive, and 8 anchor samples.
- Eight GPUs with nine class groups per rank; global class-group batch 72 versus the paper recipe's 70.
- Generated-teacher features use activation checkpointing, while positive and anchor teacher forwards are no-grad and chunked. These are memory transformations; the TFD objective remains unchanged.
- Teacher attention remains the original FP32 implementation. FP32 SDPA was rejected after a smoke test increased peak allocated memory from approximately 74.62 GiB to 75.23 GiB.
- Implementation commits: `18ac5cb`, `88e293e`, and `bdc49f4`. Server tests: 11/11 passed.

## Conclusion

The result strongly supports the hypothesis. At 180,500 updates, `8/8/8` achieves FID `1.3929`, improving on the TFD paper's reported `4/4/4` FID of `1.58` by approximately 11.8%, while using the official LMDB and official evaluation protocol. The qualitative observation of sharper images is therefore corroborated by FID.

This is strong directional evidence rather than a fully isolated causal estimate: the global class-group batch changes from 70 to 72, and the comparison uses one seed and the paper's reported baseline rather than a concurrently trained official-LMDB `4/4/4` control.
