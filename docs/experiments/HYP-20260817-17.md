# HYP-20260817-17: Wan2.2 framewise DriftWorld, five adjacent frames

## Hypothesis

Using the pretrained Wan2.2-TI2V-5B DiT with framewise Wan VAE encoding avoids
temporal VAE averaging, while five adjacent frames after the initially static
segment reduce the discontinuity observed with stride 12. Increasing generated
candidates to Bridge DriftWorld's `n_neg=64` should provide a closer drifting
field approximation.

## Temporal-force versus sample-force diagnostic

Commit `382d09f` adds an opt-in, logging-only comparison. The sample field uses
the existing 64 generated candidates at each frame position. The temporal field
uses the four generated positions from the same candidate as candidates, with
the condition frame excluded. Both paths reuse the same DriftWorld kernel,
radii, normalization, and static negative; the diagnostic does not contribute
to the training loss.

The infra smoke used seven GPUs, `MAX_ITER=2`, seed 10, and one optimizer step.
It completed with loss 7.5423 and peak memory 65.73 GB/GPU. Results from its
single measured batch were:

| Feature space | Temporal/sample normalized force | Force cosine | Temporal/sample raw kernel-force RMS |
| --- | ---: | ---: | ---: |
| Wan latent | 1.614 | 0.927 | 1.386 |
| DINOv3 block 2 | 2.213 | 0.912 | 5.086 |
| DINOv3 block 5 | 1.517 | 0.866 | 6.736 |
| DINOv3 block 8 | 1.517 | 0.832 | 11.280 |

Per-frame temporal/sample normalized-force ratios for generated slots 1--4:

| Feature space | Frame 1 | Frame 2 | Frame 3 | Frame 4 |
| --- | ---: | ---: | ---: | ---: |
| Wan latent | 0.346 | 1.008 | 2.760 | 2.341 |
| DINOv3 block 2 | 1.638 | 1.986 | 2.975 | 2.251 |
| DINOv3 block 5 | 1.328 | 1.273 | 1.938 | 1.527 |
| DINOv3 block 8 | 1.523 | 1.329 | 1.785 | 1.432 |

The temporal and cross-sample fields are strongly directionally aligned, but
they are not interchangeable. Temporal interactions are generally stronger,
and their raw relative strength grows substantially in deeper DINOv3 blocks.
In the Wan latent space the first generated frame is the exception: its
temporal force is much weaker, while later frames become stronger. This is
consistent with increasing temporal displacement away from the condition. The
result supports treating temporal drift as a separate loss term if adopted,
with independent normalization/weighting rather than replacing the current
64-sample field directly. Because this is one batch, a multi-batch run is
needed before choosing that weight.
