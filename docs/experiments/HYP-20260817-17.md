# HYP-20260817-17: Wan2.2 framewise DriftWorld, five adjacent frames

## Hypothesis

Using the pretrained Wan2.2-TI2V-5B DiT with framewise Wan VAE encoding avoids
temporal VAE averaging, while five adjacent frames after the initially static
segment reduce the discontinuity observed with stride 12. Increasing generated
candidates to Bridge DriftWorld's `n_neg=64` should provide a closer drifting
field approximation.
